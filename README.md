# 日本語シャドーイング練習アプリ

Apple Podcasts で日本語・英語の番組を探し、エピソードを追加して練習できます。

## 主な機能

- RSS の音声を AVPlayer でストリーミング再生
- SpeechAnalyzer と SpeechTranscriber を使って、端末上で字幕を区間ごとに生成・保存
- 字幕行をタップして再生位置を移動し、一文リピートや再生速度の調整
- 単語の辞書検索、AI 解説、練習時間の記録
